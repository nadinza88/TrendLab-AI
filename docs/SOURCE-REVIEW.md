# Проверка источников данных

Проверено 21 октября 2026 по официальным страницам документации.

## YouTube Data API v3

- Официальный endpoint поиска: `search.list`, тип `video`, сортировка релевантности и фильтр короткой длительности.
- Поиск даёт идентификаторы и сниппеты; дополнительный запрос `videos.list` даёт доступные статистику и длительность.
- API имеет квоты. Официальная документация сообщает отдельный лимит для `search.list`; проверь текущую квоту в Google Cloud Console перед эксплуатацией.
- API не гарантирует полноту поиска и не возвращает однозначный флаг YouTube Shorts. В интерфейсе это обозначается как короткое видео.

## TikTok

- Research API предоставляет запросы к видео и метрики, но требует одобрения исследовательского проекта и ограничен по назначению. Это не универсальный API для коммерческого создателя контента.
- Business API содержит discovery/trending endpoints, но требует бизнес-аккаунта, разрешений, advertiser ID и соответствующей авторизации; это не то же самое, что общий поиск всех роликов.
- Не включать Research API как будто он доступен всем. Не обходить CAPTCHA, вход в аккаунт или технические ограничения.

## Instagram Reels

- До выбора провайдера необходимо подтвердить реальный поиск публичных Reels по ключевым словам, поля метрик, стоимость, условия и доступность для личного использования.
- Не считать API для управления собственным профессиональным аккаунтом универсальным поиском по всей платформе.

## Решение для текущего этапа

YouTube реализован первым официальным адаптером. TikTok и Instagram честно обозначены как неподключённые. Следующий этап интеграции должен быть отдельным техническим экспериментом с провайдером, тестовым запросом, сравнением результата, ограничений и цены. Никакие результаты не имитируются.
