# TrendLab AI — критерии приёмки

- [ ] Поиск без темы не отправляется; интерфейс просит ввести запрос.
- [ ] Поиск возвращает только реальные записи от подключённого источника.
- [ ] Для каждого результата доступны оригинальная ссылка, источник и время получения.
- [ ] Если метрика скрыта или отсутствует, UI показывает «—», а не ноль и не выдуманное число.
- [ ] Сортировка по просмотрам/лайкам не подставляет отсутствующие метрики как реальные.
- [ ] Отсутствие ключа показывает инструкцию, а не тестовые результаты.
- [ ] Ошибка API, квота и пустая выдача отображаются понятным сообщением.
- [ ] TikTok и Instagram не выдаются за работающие до подключения и теста реального провайдера.
- [ ] AI-адаптация не утверждает, что видео просмотрено, если доступно только название/описание.
- [ ] Сценарий содержит оригинальный хук, структуру, текст и несколько вариантов вступления.
- [ ] Сохранённые идеи и история переживают перезагрузку того же браузера.
- [ ] Секреты отсутствуют в frontend и Git.
- [ ] Интерфейс читаем на узком мобильном экране.
- [ ] CI проходит typecheck и production build.
- [ ] Перед публикацией проверены Worker assets, секреты, API и доступность production URL.
- [ ] Не публиковать в production и не подключать платные сервисы без разрешения владельца.
