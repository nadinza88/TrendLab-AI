# Настройка TrendLab AI

## 1. Локальный запуск

- Node.js 20+
- `npm install`
- `cp .dev.vars.example .dev.vars` (Windows: скопировать файл вручную)
- Внести ключи в локальный `.dev.vars`, если они у вас уже есть.
- В одном терминале: `npm run worker:dev`
- В другом: `npm run dev`

Vite проксирует запросы `/api` на локальный Worker по адресу `127.0.0.1:8787`.

## 2. Поиск вирусных видео из YouTube, Instagram и TikTok

Для единого поиска по трём платформам используй Revid Viral Video Search. Создай бесплатный аккаунт на https://www.revid.ai/account и добавь API key в Cloudflare Worker secret `REVID_API_KEY`. По документации Revid, поиск не расходует кредиты и на бесплатном аккаунте ограничен 20 запросами за скользящие 24 часа. API возвращает исходные ссылки, доступные метрики, хуки и транскрипты. Мы используем только поиск; генерация/публикация видео Revid не вызывается. Не включай платный тариф без отдельного решения.

Если Revid не настроен, для YouTube можно использовать официальный YouTube Data API key `YOUTUBE_API_KEY` как резервный источник.

## 3. YouTube Data API

Создайте проект в Google Cloud Console, включите YouTube Data API v3 и выпустите API key. Ограничьте ключ разрешённым API и, где возможно, источниками использования. Сохраните его только как секрет Worker: `wrangler secret put YOUTUBE_API_KEY`.

API имеет квоты. Поиск стоит квотных единиц и ограничен суточным лимитом; проверяйте текущие значения в Google Cloud Console.

## 4. Генерация сценария

В `wrangler.toml` включён Cloudflare Workers AI binding. По умолчанию адаптация использует модель `@cf/google/gemma-4-26b-a4b-it` с бесплатной квотой Cloudflare Workers AI — 10 000 neurons в сутки на аккаунт; после исчерпания запросы не выполняются на бесплатном плане. Если нужно, модель можно изменить через `CF_AI_MODEL`. Альтернативно укажи `AI_API_KEY`, `AI_BASE_URL` и `AI_MODEL` для OpenAI-совместимого endpoint. Платный AI-провайдер не подключается автоматически.

## 5. Cloudflare

Проверьте привязку аккаунта и права, затем выполните `npx wrangler login`. Соберите UI командой `npm run build`, затем проверьте `npx wrangler deploy --dry-run`. Только после ручной проверки выполните `npm run deploy`. Production deploy не запускается автоматически.

**Защита доступа обязательна до production.** Сейчас API endpoints не имеют встроенной авторизации и ограничения частоты запросов. Если опубликовать Worker без защиты, посторонние смогут расходовать YouTube-квоту и вызывать платный AI endpoint. До публикации закройте приложение через Cloudflare Access (allowlist только для владельца) либо внедрите и протестируйте эквивалентную серверную авторизацию и rate limiting. Не полагайтесь на скрытый URL или проверку только на frontend.

## 6. Социальные платформы

Встроенный поиск сейчас реализован через официальный YouTube Data API. Для TikTok и Instagram нет универсального общедоступного официального API, который гарантированно даёт коммерческому создателю полный поиск коротких роликов и актуальные метрики. Не подключайте провайдера до проверки доступа, условий использования, цен, полей и ограничений. TikTok Research API требует отдельного одобрения исследовательского проекта и не является стандартным решением для коммерческого создателя.

## 7. Ограничения текущей версии

- YouTube API не сообщает достоверный отдельный флаг Shorts; выдача маркируется как короткие видео.
- Сохранённые идеи хранятся в localStorage текущего браузера.
- AI анализирует заголовок/описание и доступные метаданные, а не скрытое содержимое ролика. Если транскрипт нужен, пользователь может вставить его вручную.
- Авторизация и синхронизация сохранённого между устройствами пока не включены.
