# TrendLab AI — продуктовая спецификация

## Цель
Личный адаптивный веб-сервис для поиска коротких видео, просмотра доступных сигналов популярности и адаптации механики выбранного ролика в оригинальный сценарий под нишу и аудиторию пользователя.

## Основной сценарий
1. Пользователь вводит тему/ключевые слова и выбирает подключённые источники.
2. Сервис показывает реальные результаты, ссылки на оригиналы, доступные метрики, источник и время получения.
3. Пользователь сортирует/фильтрует выдачу, сохраняет ролик.
4. Пользователь задаёт нишу, аудиторию и цель публикации.
5. AI предлагает хук, структуру, сценарий и варианты вступления.
6. Пользователь сохраняет ролик и адаптацию для последующей работы.

## MVP
- Поиск коротких видео с доступными источниками.
- Карточки видео, ссылки на оригиналы и только фактически полученные метрики.
- Сортировка по релевантности, просмотрам, лайкам и дате; фильтр периода.
- Анализ доступных метаданных и адаптация сценария.
- История поисковых запросов и сохранённые идеи.
- Адаптивная мобильная и desktop-версия.
- Понятные сообщения об отсутствии ключа, квоте, ошибках API и неподключённых источниках.

## Не входит в первый этап
Автопубликация, генерация/монтаж самого видео, публичная регистрация и командные аккаунты, массовое скачивание роликов, доступ к приватному контенту, обход ограничений платформ, гарантированно полный поиск всех роликов.

## Правила достоверности
- Не создавать фиктивные видео, просмотры, лайки, даты или транскрипты.
- Не выдавать короткое видео YouTube за гарантированно Shorts: API не предоставляет отдельного надёжного флага.
- Не заявлять, что AI посмотрел ролик, если анализирует только название/описание.
- Не копировать уникальные формулировки автора; переносить только общие принципы формата.
- Не подключать платный источник без проверки тарифа и согласия владельца проекта.
